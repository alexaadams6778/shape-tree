# Shape Tree

A Java program that builds and manipulates a tree of geometric shapes.

## What it does
Stores various shapes (circle, rectangle, triangle) in a tree structure and provides traversal and calculation functions such as total area and depth.

## Key Features
- Tree data structure implementation  
- Recursion and traversal methods  
- Object-oriented design with inheritance (`Shape`, `Circle`, `Rectangle`, etc.)

## How to Run
Compile and run from the command line:

```bash
javac -d out src/*.java
java -cp out ShapeTreeMain
```

## Concepts Demonstrated
- Trees and recursion
- Inheritance and polymorphism
- Object-oriented programming in Java
